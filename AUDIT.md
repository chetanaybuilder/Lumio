| **AUDIT-01** | `backend/app/config.py:50`<br>`backend/app/groq_client.py:118`<br>`README.md:116`<br>`ARCHITECTURE.md:11` | Critical | LLM requests fail with 400/404 model not found on Groq API. | Default model is set to nonexistent `openai/gpt-oss-20b` (and docs reference nonexistent `qwen/qwen3.8-27b`). | **AUDIT-02** | `frontend/public/_worker.js:1-1457`<br>`frontend/functions/api/[[path]].js:1-1018` | Critical | Production deployment on Cloudflare Pages intercepts `/api/*` with a brittle JS mock API that hallucinates fake chemistry responses. | A 1450-line shadow mock backend in JavaScript was bundled into frontend dist as `_worker.js`, using a naive regex PDF parser and returning hardcoded mock chemistry flashcards/quizzes on failure. | Delete shadow mock workers from frontend (`frontend/public/_worker.js` and `frontend/functions/api/[[path]].js`). | **AUDIT-03** | `backend/app/pdf_extractor.py:133` | Critical | Multi-column textbooks extract out of order, chemistry formulas/subscripts/superscripts turn into corrupted characters. | Uses `page.get_text("text")` which ignores columns, font flags, superscripts, subscripts, and reading blocks. | Implement layout-aware extraction using PyMuPDF block/span layout detection with reading order sorting; preserve sub/superscripts (`H₂O`, `SO₄²⁻`, `10⁻³¹`) and Greek letters. |
| **AUDIT-04** | `backend/app/pdf_extractor.py:173-177` | High | Tables in documents appear twice in extracted text: once flattened in raw text, and once as markdown table. | Code appends markdown tables to `content_parts` while `raw_text` (which already contained the table words) was also appended. | Extract tables in-place or excise table bounding boxes from the text stream so table content is represented cleanly exactly once as Markdown. |
| **AUDIT-05** | `backend/app/pdf_extractor.py:200-206` | High | PDFs with mixed scanned/image pages silently emit empty chunks without alerting user or OCRing. | `PDFScannedError` is only triggered if the sum of text chars across the ENTIRE document is < 50. If 1 page has text and 10 are scanned, no error is raised. | Evaluate page-level text density; detect individual scanned pages, attempt OCR fallback or fail loudly listing the exact unreadable page numbers. |
| **AUDIT-06** | `backend/app/pdf_extractor.py:131` | Medium | Citations cite physical PDF page number instead of textbook printed page label (e.g., preface page 1 vs chapter page 1). | Code only tracks `page_no = page_idx + 1`. Does not query `doc.page_labels` or `page.get_page_labels()`. | Extract both `pdf_page_index` (0-based integer) and `printed_label` (string); expose both and cite printed label accurately. |
| **AUDIT-07** | `backend/app/text_preprocessor.py:54-70` | Critical | Chemical formulas and scientific math are mangled into English words (`α` -> `alpha`, `H₂` -> `H_2`). | `_GREEK_AND_MATH_MAP` transliterates Unicode Greek letters and subscripts into ASCII names and `_x` notation, breaking formulas. | Remove destructive replacement map; preserve authentic Unicode Greek letters, arrows, subscripts, and superscripts for KaTeX and LaTeX. |
| **AUDIT-08** | `backend/app/text_preprocessor.py:182-194` | High | Extracted PDF sentences are chopped with arbitrary hard line breaks; hyphenated words (e.g. `molecu-\nlar`) remain split. | Splits lines and rejoins with `\n` without unwrapping soft line wraps or fixing trailing hyphens. | Implement soft-wrap de-hyphenation (`([a-zA-Z])- \n([a-zA-Z])`) and join prose lines within paragraphs, preserving double-newlines for paragraphs. |
| **AUDIT-09** | `backend/app/structure_detector.py:55` | High | Real textbook sections are shattered into fragments whenever a diagram or table appears. | Line 55 marks any line starting with `[FIGURE / DIAGRAM:` or `[STRUCTURED TABLES` as a new section heading. | Figure and table markers should remain content elements within their parent section, not create artificial top-level sections. |
| **AUDIT-10** | `backend/app/chunker.py:55-60` | Critical | Markdown tables, bullet lists, and formulas are smashed into single-line whitespace word strings. | Chunker does `word for word in item["text"].split()`, discarding newlines, table formatting (`| --- |`), and formula boundaries. | Chunk by semantic blocks (paragraphs, tables, definitions, worked examples) keeping structural markdown intact, targeting 300–500 tokens with overlap. |
| **AUDIT-11** | `backend/app/chunker.py:98-99` | Medium | Chunker enters an infinite loop if `chunk_size <= overlap`. | Sliding window uses `start = end - overlap`; if `chunk_size <= overlap`, `start` never advances. | Enforce `step = max(1, chunk_size - overlap)` to guarantee progress. |
| **AUDIT-12** | `backend/app/groq_client.py:57-86`<br>`backend/app/embedding_generator.py:19` | Critical | Semantic search for Ask Lumio fails on synonyms or rephrased student questions. | Vectors are 256-dim MD5 hashed n-gram bag-of-words without semantic understanding. | Replace with a real semantic embedding model (e.g. BGE/MiniLM via fast ONNX runtime or sentence-transformers); evaluate and normalize vectors. |
| **AUDIT-13** | `backend/app/vector_store.py:33` | High | Server restart purges all document chunks and embeddings, forcing users to re-upload. | Vectors stored exclusively in global in-memory list `_store: list[dict] = []`. | Persist index on disk (SQLite / binary index) scoped by session and document ID so restarts retain documents. |
| **AUDIT-14** | `backend/app/vector_store.py:52-83, 198-202` | High | Retrieval quality is poor; exact terms like "Le Chatelier" or "Aufbau" are missed or outranked by noise. | Uses crude unweighted word overlap with arbitrary magic numbers (`+0.35`) instead of true BM25 and dense hybrid fusion. | Implement hybrid BM25 + dense vector search fused with Reciprocal Rank Fusion (RRF), followed by reranking. |
| **AUDIT-15** | `backend/app/main.py:224-258` | Critical | Notes generation ignores 90%+ of large textbooks; deep notes only cover a small sample. | `document_context` caps text at 9000 characters and takes every 10th chunk, discarding the rest of the book. | Implement map-reduce notes generation: process section by section, respect token/TPM limits, then aggregate. |
| **AUDIT-16** | `backend/app/main.py:490-532` | High | Notes contain fake generic placeholder strings in production. | If model output omits `subtopics` or `topics`, dummy strings like `"definition": "Core principles..."` are inserted. | Remove placeholder injection; use robust Pydantic schemas, validation repair/retry, or fail safely. |
